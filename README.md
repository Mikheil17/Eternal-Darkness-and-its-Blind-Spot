# Eternal Darkness and Its Blind Spot
As you explore different enviroments and follow clues to escape, you slowly discover each room connects to your life - and death.

## What It Is
A Unity VR game using Impossible Spaces for navigation.

## Key Features
- Flashlight-led gameplay mechanics
- Multiple rooms, including a children's bedroom, an office, and a hospital
- Storyline encompassing memories, growing up, and mortality

## Tech
Unity | C#

## Context
Created as part of a VXR class, focusing on VR navigation mechanics.
